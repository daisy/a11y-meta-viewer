Accessibility Metadata Viewer

How to use

The DAISY Accessibility Metadata Viewer converts the accessibility metadata in an EPUB package document or ONIX record into display statements in accordance with the W3C Accessibility Metadata Display Guide for Digital Publications 2.0.

There are currently two ways to view metadata:

  • Copy and paste an EPUB package document or ONIX metadata record into the text box.
  • Submit a metadata record via a record query string parameter.

If you do not have a metadata record but want to explore how the application works, click on the link for preconfigured files and select one of the options.

Please note that no information about your publication is collected or stored by this application. The data you load is processed locally in your browser by JavaScripts.

Running locally

If you prefer to run the application code locally, you can check out the viewer source from the GitHub repository.

The preferred way to run the viewer application is to serve the repository source using a local web server such as Apache or IIS. This approach ensures that all functionality is available.

If you do not want to use a web server, the index.html file can be opened directly in a browser to run the application. It will not be possible to load the sample files from the web page, however. If you want to use the samples, you will have to open the files in the samples directory and copy the source into the application.
